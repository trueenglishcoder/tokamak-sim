# Сплайновая граница по Сучкову

Режим `suchkov_spline_contour` добавляет отдельный способ представления LCFS.
Он основан на определении границы и сплайновой параметризации из диссертации
Е. П. Сучкова.

В диссертации граница определяется как замкнутая линия уровня `psi`
максимальной горизонтальной ширины и задаётся параметрически функциями
`R(xi)` и `Z(xi)`. В общей обратной задаче допустимые кривые перебираются с
помощью epsilon-сетей сплайнов, а выбор выполняется по невязке магнитной
диагностики.

В `tokamak-sim` поле `psi` уже известно из прямой модели. Поэтому реализована
прямая специализация геометрической части метода:

1. Берётся значение `psi` в центре плазмы и значения на лимитере.
2. Двоичным поиском выбирается самая внешняя допустимая линия уровня.
3. Линия измеряется на равномерных углах относительно центра плазмы.
4. Координаты `R(xi)` и `Z(xi)` независимо интерполируются периодическими
   кубическими сплайнами.
5. Сплайн должен быть замкнут и полностью находиться внутри лимитера.
6. Из допустимых кандидатов сохраняется кандидат максимальной горизонтальной
   ширины.

Это не реализация полной обратной задачи с epsilon-сетью и магнитными зондами.
Она не восстанавливает `psi` по диагностике, поскольку симулятор уже располагает
полным полем `psi`. CPU и batched GPU используют один контракт и одну матрицу
периодической кубической интерполяции.

Для GPU статическая геометрия лучей, дискретизация лимитера и матрица сплайна
создаются один раз при инициализации симулятора. В цикле обучения выполняется
только batched поиск уровня, интерполяция и получение 32 радиусов границы.
