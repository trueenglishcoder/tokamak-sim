# Сплайновая граница по Сучкову

Режим `suchkov_spline_contour` добавляет отдельный способ представления LCFS.
Он основан на определении границы и сплайновой параметризации из диссертации
Е. П. Сучкова.

В диссертации граница определяется как замкнутая линия уровня `psi`
максимальной горизонтальной ширины и задаётся параметрически функциями
`R(xi)` и `Z(xi)`. В общей обратной задаче допустимые кривые перебираются с
помощью epsilon-сетей сплайнов, а выбор выполняется по невязке магнитной
диагностики.

В `tokamak-sim` поле `psi` уже известно из прямой модели. Поэтому реализована
прямая специализация геометрической части метода для лимитированной плазмы.
Геометрия ограничителя является дополнительным физическим условием проекта,
а не отдельным условием исходной постановки диссертации.

Искомая граница определяется как

```text
Gamma* = argmax_Gamma (max_Gamma R - min_Gamma R)
```

с ограничениями:

1. `Gamma` является замкнутой линией уровня `psi = const`.
2. `Gamma` содержит магнитную ось.
3. `Gamma` целиком лежит внутри или на поверхности ограничителя:
   `Gamma subset closure(Omega_limiter)`.
4. Итоговая limited LCFS касается ограничителя с допуском, связанным с шагом
   сетки. Строгое нахождение внутри без возможности касания не используется.

Алгоритм:

1. Берётся значение `psi` в центре плазмы и плотно дискретизируется поверхность
   ограничителя с шагом не грубее половины ячейки расчётной сетки.
2. По значениям `psi` на ограничителе определяется уровень первого возможного
   контакта при движении от магнитной оси наружу.
3. Двоичным поиском находится супремум допустимых уровней между магнитной осью
   и уровнем контакта.
4. Для каждого кандидата находятся 32 контрольные точки линии уровня на лучах
   из центра плазмы.
5. По контрольным точкам отдельно строятся периодические кубические сплайны
   `R(xi)` и `Z(xi)`.
6. Сплайн проверяется в 256 точках: он должен оставаться замкнутым, содержать
   магнитную ось и находиться внутри или на полигоне ограничителя.
7. После завершения поиска один раз проверяется расстояние от выбранной LCFS до
   ограничителя. Оно должно быть не больше двух шагов расчётной сетки.
8. Из сплайновой кривой вычисляются 32 радиуса, используемые observation,
   reward и oracle targets.

Двоичный поиск предполагает семейство вложенных магнитных поверхностей вокруг
одной магнитной оси. Для используемых limited-разрядов T15 это является
контрактом режима. Диверторные конфигурации с X-точкой должны обрабатываться
отдельным алгоритмом сепаратрисы.

CPU и batched GPU используют одинаковые числа контрольных и проверочных точек,
одну матрицу периодической кубической интерполяции и одинаковые геометрические
условия допустимости. На GPU матрица сплайна, углы, лучевые ограничения и
дискретизация ограничителя создаются один раз при инициализации симулятора.
Проверка контакта выполняется только для итогового кандидата, чтобы не добавлять
дорогой расчёт расстояний в каждую итерацию двоичного поиска.

Это не реализация полной обратной задачи с epsilon-сетью и магнитными зондами.
Она не восстанавливает `psi` по диагностике, поскольку симулятор уже располагает
полным полем `psi`.
